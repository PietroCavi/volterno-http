**Volterno**  
volterno as a name doesn’t really mean anything, it’s a made up name for my server, I always wondered how websites work. After having used different libraries and frameworks for university projects, and after seeing the amount of bloat used to create something so simple I wanted to create a minimal 100% C code, no libraries (aside from system/linux ones) backend.

I was sort of successful ([http\://volterno.ddns.net](http://volterno.ddns.net)), you can see the old backend code in the **`old/`** directory in this repo (don’t mind the frontend, it’s just random stuff).  
My old code has very lackluster POST support, there are no POSTs currently implemented, they can be done, for sure, but not elegantly.

This repo contains the current iteration, I’ve restarted completely, with a more careful approach and updated header handling, it will probably be done by early 2027\.
