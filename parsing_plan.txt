base
    Can always be declared; It must be a specific file, since it's too important to leave unspecified. 
    The base refers to a GET, always, and it is the file sent when "/" is requested.

root
    Extremely important; it must be declared before any file or dir.

method
    Can also be declared before root, but must come before file or dir. The method is valid until the next 
    method encountered (GET, POST, PUT, DELETE, PATCH).

functions
    Like method, it can be declared before root, file and dir. It is also valid until the next function 
    declaration.

file
    Indicates the path to a file that will be the subject of the request. In the case of a GET, it is sent.

dir
    Indicates the path to a directory. In the case of a GET, every element inside it can be sent.

-> <name>
    Indicates the function to execute for this request. These functions take as arguments: 
    int socket, char* header.

@
    Single line comment.


If a definition is done more than once... the parser will fail and throw and error!
